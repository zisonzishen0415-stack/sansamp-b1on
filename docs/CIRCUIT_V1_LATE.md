# BDDI V1 后期型 — 逐级拆解台账(白盒建模用)

> 依据:`references/09_284_05_tech21_sansamp_bass_driver_di_v1l_schematic.png`
> (kanengomibako traced,2022)。状态:**初读**,数值以图为准,建模前逐项复核。
> 每条格式:级 → 拓扑 → 已读元件值 → 建模映射(拟)。

## 0. 电源/偏置

- 9V(BT1/X4)→ D5 → R61/R37(470Ω,变体:220Ω×1/×2 并联)、R59/R62(68Ω)→
  C6(220µ)/C5(47µ);下侧 R32(10k)+C11(10µ)/C38(47µ) → **VCOM 半电源偏置**。
- 音频路径一律以 VCOM 为参考(单电源运放偏置) → ZDL 实现:全链 0V 参考即可
  (可省偏置,数字化后无需 VCOM)。

## 1. 输入级

- X3 IN → C4(47n) → R10(10k);R1/R2(1M/1M)分压至 VCOM。
- **IC2B(TLC2264)**:同相输入缓冲(单位增益)。→ 建模:直通(或加输入 RC)。

## 2. PRESENCE 塑形级(IC2A)

- 反馈/输入网络:R16(100k)、C19(4.7n)、C18(22n)、C17(22n)、C26(100p)、
  R26(10k)、R24(3.3k)、R110(10k)、C31(10n)、C32(100p)、**PRESENCE VR(B100k)**、
  R11(2.2k)、R23(10k)输出。
- 另含 **~430Hz 固定中频凹槽**(V2 解析页确认此电路在 V1 初/后期都存在,
  V2 取消)——具体网络(V1L 图右上独立小电路)待逐点核。
- → 建模:2~3 个双二阶(一个参数化 presence 峰/架 + 一个固定 notch@430Hz)。

## 3. 灌封模块 CH34-x(= 管模拟/失真核心)

外壳 CH34-5/CH34-9(与 Character 系列 CH33-6 同族),内含双运放 **IC10A/IC10B
(TLC2262)**:

- 输入:C28(2.2µ)耦合自 IC2A。
- IC10A:增益/缓冲级(R25 100k、R105 100k、R101 220k、C8(47n?) 待核)。
- **IC10B:DRIVE 增益级(VR1 B100k),反馈环内 D100/D101 = DZ2C3V3 双 3.3V
  稳压管(对置)** ← **全部失真的发生地**。
- 元件:R17(10k)、R104(不用)、R103(不用)、R102(220k)、R106(220k)、
  C7(47n?)等,逐点待核。
- 输出:R48/R49(3.3k/3.3k)、R18(100k)、C23(47n)、**C13(10µ)**、R34(3.3k)。
- → 建模:
  - 增益级(带 DRIVE 参数)→ 线性增益;
  - 稳压管对 = 非线性元件:**I-V 曲线**(Zener knee 3.3V + 正向 0.7V),
    实现 = 逐样本牛顿迭代(2~3 步)或查表+插值(预算远够);
  - **TLC2262 输出削顶/摆率** = 第二非线性(频率相关!),BDI21 换 TL074 差异的
    根源——建议纳入,做法:输出限幅 + 简化摆率(一阶)。
  - **稳压管结电容**(V2 页提到端子间容量明显且批差大)= 与增益级并联的小电容
    (几 pF~几十 pF),产生 DRIVE 时的高频滚降——影响音色,列入。

## 4. 箱体模拟滤波网(IC2C / IC2D,TLC2264)

- 模块输出 → C13 → **IC2C**(滤波级 1:R38?/C14(10n)/C33(2.2µ)/R35(100k)/
  R34(3.3k)/C34(470p)/R36(3.3k)/R89(6.2k)/C10(4.7n)/C27(22n)/C30(?));
- **IC2D**(滤波级 2:R12(10k)/R27(22k)/C42(4.7n)/**C0 2.2µ\***/C12?);
- \* C0 = 2010 前后追加的低频补偿(部分个体无),→ 建模做可选项(v1l-C0 on/off,
  或并入 Mode)。
- → 建模:该网络是纯线性多极点滤波 → 数值化(链 4~6 个双二阶/一阶,
  按传递函数逐段推或整体 fit);**无 IR**。

## 5. BLEND / LEVEL

- **BLEND VR6(B100k)**:干路(来自 IC2B 输出侧)×湿路(第 4 节输出)混合。
- **LEVEL VR4(B100k)** → **IC3A(TLC2264)** 缓冲。
- → 建模:标准干湿混合 + 输出增益。

## 6. 音调网络(IC3C)

- **BASS:** R51(8.2k)/C21(4.7n)/VR2?(B100k)/R55(3.3k)/C15(220n)/R52(3.3k)/
  R53(100k)/C16(10n)——**peaking 型**(V1L 改动点);
- **TREBLE:** C20(1n)/R28(1M)/R29(1M)/C29(22n)/R33(100k)/**TREBLE VR(B100k)**/
  R54(2.2k);TREBLE 电位器 1 脚电阻并联电容(V1L 特有高频下压);
- (电位器编号 VR2/VR3 在两图中复用,建模以功能为准。)
- → 建模:两个参数化 peaking 双二阶,系数按电位器位置插值(先算 3~5 个位置
  的系数表,运行时 `set_param` 双线性/线性插值——同 AmpNeve tone 做法)。

## 7. JFET 级与输出

- **T1/T2 = MMBFJ202(JFET)** 两级(自偏置),位于音调后输出路径;
- **IC3D(TLC2264)** 输出级;R56(10k)/R6(2.2M)/C44(100n)/C43(2.2µ) =
  INST/LINE 高通选择(SW6A);
- OUT(X2);XLR 支路(IC4A/IC4B TLC2262 + X1 变压器 + phantom)——**ZDL 版本略去**。
- → 建模:JFET 级 = 软饱和(平方律/指数近似)+ 微偏置;输出高通按 INST/LINE。

## 8. 开关/逻辑(与音色无关,ZDL 略)

- HEF4013 双触发器 + LED + 脚踏;V2 起加 FET 旁路开关。
